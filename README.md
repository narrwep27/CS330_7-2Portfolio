### How do I approach designing software?

My work on my project helped me to apply object-oriented programming principles, such as encapsulation, and packaging my code into reusable functions. I used encapsulation by ensuring the classes I used retain control of their own state. The methods used to adjust the state of a class were privately available to use only by the owning class. This ensured that outside classes were not able to use these methods. I could use this design process for future work by making sure to bundle together methods that use and/or modify data into a singular class.

### How do I approach developing programs?

This project required much trial-and-error development. I would create a model and pass in vector transformation values. I had a vague idea of how the model would be positioned, scaled, and rotated but would not know exactly what it looked like until I started up the project and viewed the 3D scene for myself. I had to go through lots of starting and restarting so that I could see the result of my transformation adjustments. Iteration played a big role in the development of this project as well. When building the pieces of the models in my scene, I found that certain aspects of the code would repeat. I found that I could make the code more concise and readable by going back and replacing the repeated code with methods. Code that first began as hand-writing the different transformation values of each individual mesh ended in replacing many repeated mesh-creation code with simplified methods that made the code easier to understand.
